# CHAGEE Sales Analytics | 霸王茶姬新茶饮销量可视化平台

本项目是一个基于 **Python Flask + MySQL + Pyecharts** 的交互式可视化大屏，旨在通过真实业务数据，深入分析新式茶饮的消费趋势、用户偏好与门店运营状况，为品牌运营策略提供数据支撑。

## 🛠️ 技术栈
- **后端框架**：Python Flask (轻量级 Web 后端)
- **数据存储**：MySQL (存储海量订单数据)
- **数据清洗**：Pandas (剔除异常、特征工程)
- **前端可视化**：Pyecharts + HTML/CSS/JS (交互式动态图表)

## 📂 项目结构
- `backend/`：后端数据接口与数据库连接逻辑
- `frontend/`：前端静态页面与可视化图表渲染代码
- `data/`：项目脱敏后的模拟数据集与 ETL 脚本
- `main.py`：项目 Web 服务的启动入口

## 📊 核心功能与分析洞察
1. **爆款单品销量排行**：通过柱状图对比“伯牙绝弦”、“桂馥兰香”等核心产品的销量，精准定位引流爆品。
2. **用户口味偏好洞察**：饼图展示甜度与温度选择分布，发现“五分糖”与“正常冰”是绝对主流，揭示健康低糖的消费趋势。
3. **季节性需求波动**：折线图展示月度销量与温度需求走势，为夏季冰饮备货与冬季热饮营销提供库存预警。
4. **区域门店营收热力图**：动态地图展示各城市门店的销售分布与营收排名，识别高潜力市场。

## 🚀 如何启动项目
1. 创建 MySQL 数据库，导入 `data/` 目录下的 SQL 初始数据。
2. 修改 `backend/` 下的数据库连接配置。
3. 在终端安装依赖：`pip install -r requirements.txt`
4. 运行项目：`python main.py`
5. 浏览器访问：`http://127.0.0.1:5000`pip
